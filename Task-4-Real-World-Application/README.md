## Application Overview
This project explores the application of deep-learning-based hyperspectral image classification in precision agriculture. The proposed system uses hyperspectral imagery to identify different land-cover and crop categories.

## Proposed Application
The hybrid RCNN + 3D-CNN + U-Net architecture combines spatial and spectral–spatial features to classify 16 land-cover classes from the Indian Pines dataset.

## Real-World Relevance
- Crop-type identification and mapping.
- Agricultural land-cover monitoring.
- Precision agriculture planning.
- Supporting data-driven agricultural decisions.
