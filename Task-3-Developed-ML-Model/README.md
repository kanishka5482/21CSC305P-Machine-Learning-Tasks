## Project Description
This project implements a hybrid deep-learning architecture combining a Recurrent Convolutional Neural Network (RCNN), a 3D Convolutional Neural Network (3D-CNN), Feature Fusion, and a U-Net decoder for hyperspectral image classification.

## Dataset
Indian Pines corrected hyperspectral dataset:
- Image dimensions: 145 × 145 × 200
- Number of classes: 16
- Labelled pixels: 10,249

## Model Performance
- Overall Accuracy: 88.29%
- Average Accuracy: 92.66%
- Cohen's Kappa: 0.8647
